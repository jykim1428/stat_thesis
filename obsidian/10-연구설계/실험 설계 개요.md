# 실험 설계 개요

| 항목 | 내용 |
|---|---|
| **데이터** | Binance 현물 USDT, 암호자산 8종, **1시간봉**, 2021-01-01~2025-12-31 |
| **자산** | ADA, AVAX, BNB, BTC, DOGE, ETH, SOL, XRP (알파벳순) |
| **배분 대상** | 자산 8 + 현금 1 = **9개** |
| **환경** | FinRL `PortfolioOptimizationEnv` 벤더링 |
| **관측** | **(3, 8, 50)** = 가격피처 3 × 자산 8 × lookback 50시간 |
| **행동** | **(9,)**, `Box(-10, 10)` → softmax 정규화 |
| **보상** | 로그 수익률 `log(V_t / V_{t-1})` |
| **알고리즘** | PPO (Stable-Baselines3 2.9.0) |
| **정책망** | MLP vs Transformer (특징추출기만 교체) |
| **거래비용** | 편도 **0.1%** |
| **학습량** | **51,200 스텝** (전 조건 동일) |
| **평가** | [[Walk-Forward 평가 설계|국면 보존 확장 윈도우 2-fold 전진 평가]] |
| **시드** | 최종 OOS **5개** (42~46) |
| **통계** | [[평가 지표와 통계 검정|block bootstrap + Holm 보정]] |

## 시장 국면

| 국면 | 기간 | 용도 |
|---|---|---|
| 상승(2021) `bull_2021` | 2021-01-01 ~ 2021-11-09 | 학습 |
| 하락(2022) `bear_2022` | 2021-11-10 ~ 2023-01-01 | 학습 |
| 횡보(2023) `side_2023` | 2023-01-02 ~ 2023-10-15 | 검증 (Fold 1) |
| **상승(2024)** `bull_2024` | 2023-10-16 ~ 2025-01-01 | **OOS (Fold 1)** |
| **조정(2025)** `choppy_2025` | 2025-01-02 ~ 2025-12-31 | **OOS (Fold 2)** |
