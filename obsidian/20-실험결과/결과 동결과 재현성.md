## 시드 프로토콜 공시 ⭐

> [!warning] 반드시 각주로 밝힐 것
> 최초 프로토콜은 **3-seed(42~44)**였고, "최소 5시드" 원칙에 맞춰
> **OOS 확인 후** 시드 45·46을 두 정책·두 fold에 동일하게 추가한
> **post-hoc robustness extension**이다.

시간 순서:
1. 2026-09-02 — 3-seed OOS 완료
2. 2026-09-03 — "최소 5시드" 원칙을 마일스톤 문서에 추가
3. 2026-09-07 — 시드 45·46 확장 실행

→ "OOS 결과를 본 뒤 조건을 바꾸지 않는다"는 원칙과 **문자 그대로는 충돌**

### 그래도 문제가 없는 이유
- 후보·하이퍼파라미터 변경 없음
- 두 정책·두 fold에 **동일하게** 적용 → cherry-picking 없음
- 후보 선택은 3-seed로 이미 확정 → 모형 선택 누수 없음
- 원 3-seed 결과 별도 보존, 결론 동일

> [!danger] "사전 계획된 5-seed"로 쓰면 허위 서술

> [!danger] 실험 동결 커밋을 checkout하면 안 된다
> `10892a1`을 checkout하면 **분석 스크립트 3개의 체크섬이 전부 달라진다**
> (동결 이후 분석 코드가 수정됐기 때문). 실험 결과의 동결 기준과
> 사후 분석 코드의 커밋은 별개다.

### A. 무결성 검증 (대부분 이것만 하면 됨)

manifest의 체크섬 61건과 실제 파일을 대조. **재실행 불필요.**
일치하면 수치는 유효하다.

### B. 분석만 재실행 (PPO 재학습 없음)

1. `analysis_lineage.scripts[*].last_commit` 확인 — **스크립트마다 다름**
2. 각 스크립트를 그 커밋 기준으로 맞춤 (현재 main의 체크섬이 기록과
   같으면 main 사용 가능)
3. **`.venv/bin/python`으로 실행** (다른 인터프리터는 패키지 버전 미기록)
4. 출력 위치가 동결 폴더가 **아니다**:

   | 스크립트 | 출력 |
   |---|---|
   | `walk_forward_statistical_tests.py` | `results/walk_forward_statistical_tests/` |
   | `walk_forward_behavior_diagnostics.py` | `results/walk_forward_behavior_diagnostics/` |
   | `walk_forward_visualizations.py` | `results/walk_forward_figures/` |
   | `walk_forward_freeze_manifest.py` | `frozen_summaries/manifest.json` |

> [!warning] 동결 폴더는 재생성되지 않는다
> `frozen_summaries/`의 요약 CSV 11개는 **어떤 스크립트도 만들지 않는다**
> (수동 보존 사본). 같은 폴더의 `statistical_tests.json`도 동결 사본이며
> 통계검정 스크립트는 자기 폴더에 쓰고 이 사본을 갱신하지 않는다.
> 비교하려면 새 출력과 동결 사본을 직접 대조할 것.
> manifest는 생성 시각·HEAD를 기록하므로 바이트 동일성 기대 불가.

### C. 전체 재현 (원천 데이터부터)

`walk_forward_orchestrator.py` 필요. 원천 DB와 모형 파일은 **저장소에
없다**(용량). 결정론 모드 미강제라 비트 단위 동일성 보장 안 됨.

### 결과가 다를 때 — 원인 좁히기

1. **입력** 체크섬이 manifest와 같은가
2. **코드** 체크섬이 `analysis_lineage`와 같은가
3. **환경** `.venv`로 실행했는가
4. **경로** 동결 사본을 본 것인가 새 출력을 본 것인가

전부 확인 후에도 다르면 보고할 것. "freeze 이후 코드 변경"은
여러 원인 중 하나일 뿐이다.

## AI 보조 코드 검토 및 재실행 검증

코드·분석 절차를 LLM 기반 코드 검토 도구로 반복 검토했다.
**독립적인 인간 연구자의 동료 검증이 아니다.** 교차 확인 항목:
- 검정통계량 정의와 재표집 단위 (공동 재표집)
- gross/net 일관 적용
- bootstrap 시드 결정론성
- turnover 정의
- 표준화 통계량 추정 구간
- 행동 진단 분석 대상 선택

> 제기된 사항은 **모두 실제 재실행으로 재현 확인 후** 반영.
> 코드 검토만으로 판단하지 않음.
