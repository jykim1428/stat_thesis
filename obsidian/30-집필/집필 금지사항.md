# 집필 금지사항

> 세 명 공통. 위반 시 통계적으로 **틀린 문장**이 되거나 **허위 서술**이 된다.

## 🚫 1. "통계적으로 동등하다" — 최우선 금지

| | |
|---|---|
| ❌ | "PPO와 벤치마크가 통계적으로 **동등하다**" |
| ❌ | "PPO가 벤치마크와 **차이가 없다**" |
| ✅ | "Sharpe 차이가 **0과 다르다는 통계적 증거를 얻지 못했다**" |

비유의는 동등성의 증거가 아니다. equivalence test 미수행.
→ [[통계 검정 결과]]

## 🚫 2. "PPO가 이겼다/졌다"로 단순화

국면별로 다르고, 통계적으로는 어느 쪽도 입증되지 않았다.

## 🚫 3. "사전 정의된 선택 기준"

✅ "validation 결과 검토 후 확정하고 OOS 확인 전 동결한 기준"

## 🚫 4. "사전 계획된 5-seed"

✅ "최초 3-seed, OOS 확인 후 후보 변경 없이 추가한 **post-hoc
robustness extension**"

## 🚫 9. 버그 수정 이력을 고백조로 서술

| | |
|---|---|
| ❌ | "초기 구현에서 turnover를 weights 차이로 계산했으나 오류였다" |
| ✅ | "turnover는 목표 비중과 직전 사후 비중의 차이로 정의한다. 사후 비중끼리 비교하면 가격 변동분이 거래량으로 계상되어 1.22~1.46배 과대계상된다" |
