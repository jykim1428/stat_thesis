## [1장 재검토]

**항목별 (절) 현재 서술 → 문제 → 제안**

1. **(1.2 RQ2)** "정책망의 특징 추출 구조로서 Transformer가 MLP보다 우수한가?"
   → 두 모형은 구조뿐 아니라 파라미터 수·출력 차원·최종 설정이 달라 구조 자체가 성과 차이를 일으켰다고 분리해서 설명하기 어려움(3.3.1, 4.4, 5.2.2)
   → "MLP와 Transformer는 어떠한 성과 차이를 보이는가?"로 변경하고, 각 모형군의 검증 선택 설정 기준 비교임을 한 줄 덧붙임

2. **(1.2 RQ3)** "학습된 정책은 서로 다른 시장 국면에 일반화되는가?"
   → 표본외(OOS) 평가 국면이 상승 국면과 조정 국면 2개뿐이고 국면 경계도 사후 지정(3.5.3, 5.4)이라 여러 시장 상황에 일반화되는 능력을 입증했다고 말하기 어려움. 또한 5.2.1=RQ1, 5.2.2=RQ2이나 5.2.3은 정적 배분의 원인을 다루어 RQ3에 대한 직접 답이 5.2에 명시되어 있지 않음
   → "상승 국면과 조정 국면에서 정책의 성과와 투자 비중 변화는 어떻게 나타나는가?"로 변경. 

3. **(1.2 또는 1.3 끝)** 연구의 기여 서술 없음
   → 작업 지시서는 본 연구의 기여를 "성과가 아니라 평가 절차"로 확인하라고 했고 5.3도 이를 명시하나, 1장에는 학술적·실천적 기여가 명시적으로 서술되어 있지 않음. 1.2 목적문이 "우수성 주장이 아님"까지는 말하나 기여가 평가 절차임은 예고하지 않아, 검증 자체가 목적이라고만 되어 있어 논문 전체를 관통하는 핵심 기여가 약해 보임
   → 5.3과 수미상관을 이루는 한 문장 추가 권장. 연구 범위·한계의 나열은 1장에 불필요(5.4 소관, 현재 5.4와 모순되는 서술도 없음). 문장 추가 여부는 준영과 협의
   - 문장 예시 (1): "따라서 본 연구의 주된 기여는 새로운 모델의 제안이나 우수한 성과 달성이 아닌, 강화학습 포트폴리오 연구에서 성과 지표와 정책행동(목표 비중)을 반드시 병행 보고해야 한다는 방법론적 평가 원칙과 절차를 제시하는 데 있다."
   - 문장 예시 (2): "본 연구는 강화학습 기반 포트폴리오 전략의 우수성을 단정하기보다, 서로 다른 시장 국면에서의 성과와 투자 비중 변화를 비교하고 이를 통계적으로 검토했다는 점에서 의의를 갖는다."

4. **(1.2, 1.3)** "PPO", "OOS"
   → 첫 등장 병기 누락(용어사전 §1)
   → "Proximal Policy Optimization(PPO)", "표본외(out-of-sample, OOS)"

5. **(1.1 문단 2)** "위험 균형", "동일가중", "최소분산"
   → 용어사전 §7 표기와 불일치
   → "위험균등(Risk Parity)", "동일가중(Equal-Weight)", "최소분산(Minimum-Variance)" 첫 등장 병기

6. **(1.3)** "Walk-Forward 검증 설계"
   → 용어사전 §5 정식 명칭은 "국면 보존 확장 윈도우 2-fold 전진 평가"(k-fold 교차검증 아님)
   → 정식 명칭 사용. "교차검증"으로 바꾸지 않음

## [연결 점검]

**1. (2.4.1 데이터 누수) ↔ (3.2.1; 3.1.4, 3.7.5에서 참조) : 불일치(수정 필요)**

- 2.4.1 마지막 단락은 TrainStandardizeWrapper가 실제 실행 경로에서 사용되었는지 코드 분석만으로 완전히 확정하기 어려우므로, 최종 실험 결과에 대한 표준화 적용 여부는 별도로 확인할 필요가 있다고 서술함.
- 3.2.1은 본 장의 모든 walk-forward 학습과 평가에는 적용되지 않았다고 확정적으로 서술함(10/19 리뷰 반영).
- 앞장의 불확실한 서술이 3장의 확정적 사실과 충돌하므로, 2장 담당 유지에게 해당 문장을 3장에 맞게 확정적 서술로 보강해 달라고 전달.
- 참고: 3.1.4 제목은 '특징 생성 및 train-only 표준화'이나 본문은 기술지표와 환경 내부 비율 변환만 설명하고, train-only 표준화가 무엇이며 실제 실험에 적용되었는지에 대한 설명이 부족함(3.2.1에는 명시). 3.1.4에 보완할 내용은 다음과 같음.
  - train-only 표준화 기능은 별도로 구현하고 검증했음
  - 최종 walk-forward 학습과 평가에는 적용하지 않았음
  - 실제 PPO 입력에는 환경 내부의 직전 시점 대비 비율 변환만 적용했음

**2. (2.4 쟁점 목록) ↔ (3.7 서두) : 불일치(표현 수준, 내용상으로는 대응)**

- 2.4 항목: 데이터 누수, 다중비교, 단일 결과 중심 보고, 거래비용 누락
- 3.7 서두: "2장에서 검토한 바와 같이 암호자산 백테스트 연구에서는 데이터 누수, 다중비교, 단일 시드 보고, 결과의 사후 조정이 반복적으로 지적되어 왔으며, 본 연구는 이에 대응하는 통제를 설계에 포함했다."
- 2.4.4 거래비용의 "사후적"은 학습 때는 비용을 reward에 넣지 않고 평가할 때 0.1%를 나중에 차감한다는 뜻이다. 3.7의 "결과의 사후 조정"은 결과를 본 뒤에 설정이나 선택을 바꾼다는 뜻이라 서로 다른 개념이며, 거래비용은 3.2.2에서 따로 다루므로 3.7 서두에 없어도 문제 아님.
- 3.7의 두 항목은 2.4.2(데이터 스누핑·백테스트 과적합, 모델·하이퍼파라미터·시드·fold 반복 비교)와 2.4.3(선택편향)의 내용을 압축한 것으로 읽을 수 있음. 다만 2장에는 같은 이름의 소제목이 없어 독자가 대응을 바로 찾기 어려움.
- 제안: 3.7 서두의 표현을 2장 어휘에 맞춤. 2장은 수정하지 않아도 됨. (유지·준영 협의)
  - "단일 시드 보고" → "단일 결과 중심 보고"
  - "결과의 사후 조정" → "결과의 사후 선택(데이터 스누핑)"

**3. (2.4.2 다중비교, 2.5) ↔ (3.6.3 다중비교 보정) : 부분 불일치**

- 2.4.2·2.5는 Holm 보정이 FWER을 통제한다고 서술함. 3.6.3은 p값이 null-centered가 아니라 엄밀한 FWER 통제는 주장할 수 없다고 함.
- 제안: 2장을 "엄밀한 FWER 통제 달성"이 아니라 "다중비교에서 유의성을 과대 해석하지 않도록 Holm 보정을 적용"하는 수준으로 완화.
- 용어: 2.4.2는 제1종 오류율을 FWER로 표기하고 3장은 풀어서(family-wise error rate) 표기하므로 용어 통일 필요.

**4. (2.4 전체) ↔ (5.3) : 부분 불일치(보완 사항)**

- 5.3의 원칙(성과·행동 병행 보고, 비유의 해석, 사후 변경 공시)이 2.4에서 선행 제기되지 않음.
- 제안: 2.4 마지막 부분이나 방법론적 고려사항을 정리하는 문단에 한 문장 정도로 선행 언급. 반드시 고쳐야 하는 오류라기보다 논리 흐름을 보완하는 사항이며, 5.3의 사후 변경 공시는 실제로 기록한 변경 사항에 맞춰 표현.
  - 문장 예시: "강화학습 기반 포트폴리오 전략을 평가할 때는 수익률과 위험 지표뿐 아니라 실제 투자 비중의 변화도 함께 살펴볼 필요가 있으며, 통계적으로 유의하지 않은 결과의 해석과 분석 과정에서 발생한 사후 변경 사항도 투명하게 제시해야 한다."

**5. (2.1 전통 전략 4종) ↔ (4.3 벤치마크, 표 4-3) : 일치**

- B&H BTC, 동일가중, 최소분산, 위험균형 4종 일치. 2.1의 Markowitz 설명이 4.3 주석(Minimum-Variance)과 자연스럽게 이어짐.
- 표기 불일치: 2.1의 "위험균형"→"위험균등", "Minimum Variance"→"Minimum-Variance"(용어사전 §7).

### 4.3절 참조 — 확정 오류

- 4.3에서 번호가 표시된 소절은 4.3.1, 4.3.2뿐이며, "비유의 결과의 해석 범위"는 4.3.2 안의 소제목이다.

- 제안: 참조 대상(검정 결과 요약 / 비유의 해석 원칙)을 실제 위치에 맞게 정정. 번호만 바꾸지 말고 어느 설명을 가리키려던 것인지 확인 후 수정.

확인한 참조 위치

- 4.6 ②: "이는 동등성의 증거가 아니라 차이를 판별할 증거가 확보되지 않았다는 뜻이다(4.3.4절)."

확인한 참조 위치
