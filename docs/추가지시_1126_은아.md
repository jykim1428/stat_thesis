## 1. 5.4.3 맨 앞에 "학습·평가 목적 불일치"를 최우선 한계로

**위치:** 5장 > 5.4.3 설계상의 한계 > 첫 항목("하이퍼파라미터 탐색이 제한적이다.") **앞에** 새 문단

**이유:** 디펜스에서 가장 먼저 공격받을 지점이다. 지금은 5.4.3 넷째 항목("거래
환경이 단순화되어 있다.")의 마지막 문장에 한 줄로만 들어가 있다.

**추가 (그대로 써도 됨):**

> 학습 목적과 평가 목적이 일치하지 않는다. 학습 환경은 거래비용을 0으로 두었고
> 상태에 직전 보유 비중을 포함하지 않았다(3.2.1절, 2.4.4절). 따라서 정책은 거래비용을
> 고려한 배분 문제가 아니라, 행동이 다음 상태에 영향을 주지 않는 시점별 무비용
> 배분 문제를 학습했다. 반면 성과 평가는 거래비용 0.1%를 차감한 순수익률로
> 수행했다. 본 연구의 결과는 이 설정에서 학습한 정책을 순수익률 기준으로 사후
> 평가한 것으로 한정해 해석해야 하며, 거래비용과 직전 보유 비중을 반영한 재학습은
> 후속 과제로 남긴다(5.5.1절 ②·⑤).

**함께 수정 — 중복 제거:** 같은 5.4.3의 "거래 환경이 단순화되어 있다."로 시작하는
문단 마지막 문장

> "또한 학습 신호에는 거래비용이 반영되지 않고 평가 단계에서만 차감된다(3.2.2절)."

→ **삭제.** 위 새 문단이 대신한다.

## 2. 3.1.1 시가총액 기준일·출처 — **은아 확인 필요**

**위치:** 3장 > 3.1.1 > 첫 문단 "자산은 시가총액 상위 종목 중 전 기간 데이터
가용성을 기준으로 선정하였다."

**문제:** 심사위원이 "어느 시점, 어느 사이트 기준 시가총액이냐"고 물으면 답이 없다.
저장소 어디에도 기록이 없어서 **자산을 고른 은아만 답할 수 있다.**

**할 일:** 당시 기준을 확인해 아래 빈칸을 채운다.

> 자산은 ______(출처, 예: CoinMarketCap)의 ______(기준 시점, 예: 2026년 7월 데이터
> 수집 시점) 시가총액 상위 종목 중, 스테이블코인을 제외하고 전 기간 데이터 가용성을
> 기준으로 선정하였다.

- "스테이블코인을 제외하고"처럼 **실제로 적용한 제외 기준**이 있었다면 적는다
  (USDT·USDC가 상위권인데 빠져 있으니 아마 있었을 것). 없었다면 지운다
- 기준을 정확히 기억하지 못하면 **지어내지 말고** 준영에게 알릴 것. 그 경우 "본
  연구는 데이터 수집 시점(2026년 7월)의 시가총액 상위 종목을 대상으로 했으며, 기준
  자료는 기록하지 않았다"로 한계를 밝히는 쪽으로 정한다

## 3. 3.2.2 거래비용 0.1%의 출처 표기

**위치:** 3장 > 3.2.2 > 첫 문단 "거래비용은 편도 0.1%(cost_rate = 0.001)로
설정했다. 이는 본 연구의 자료 출처인 Binance 현물 시장에서 일반 등급 사용자에게
적용되는 기본 수수료율(메이커·테이커 각 0.1%)과 같은 수준이며, …"

**문제:** 5차에서 근거 문장은 이미 들어갔다(유지 반영). **출처 표기만 없다.**

**할 일:** Binance 현물 수수료 안내 페이지에서 일반 등급(VIP 0)의 메이커·테이커
수수료가 0.1%인지 확인하고, 문장 끝에 출처를 단다.

> …기본 수수료율(메이커·테이커 각 0.1%)과 같은 수준이며**(Binance, 접속일
> 2026-11-__), BNB 결제 할인 등 수수료 감면은 적용하지 않았다.** 모든 정책과
> 벤치마크에 동일하게 적용된다. …

- 접속일을 실제 확인한 날짜로 채운다
- 참고문헌에 웹 문서로 추가: `Binance. (n.d.). Trading fee rate. 페이지 URL
  (접속일 2026-11-__)` — 양식은 유지가 다른 항목과 맞춘다
- **0.1%가 아니면** 문장을 바꾸지 말고 준영에게 알릴 것

## 4. 3.1.2 피처 테이블 17열 / 동결 DB 19열 구분

**위치:** 3장 > 3.1.2 > "기술지표는 종목별로 계산한 뒤…"로 시작하는 문단

**문제:** 본문은 "17개 열"이라고 하는데, 동결 메타데이터(`freeze_metadata.json`)와
데이터 딕셔너리는 19열이다. 둘 다 맞다 — 학습용 피처 테이블은 17열, 동결 DB는
여기에 `regime`·`split` 열이 붙어 19열이다(확인 완료). 구분만 해 주면 된다.

**수정:**

> …그 결과 분석 기간의 최종 피처 테이블은 자산당 43,737행씩 총 349,896행(17개 열)으로
> 구성되며, …
> →
> …그 결과 분석 기간의 최종 피처 테이블(features.parquet)은 자산당 43,737행씩 총
> 349,896행(17개 열)으로 구성되며, … **동결 데이터베이스에는 여기에 국면(regime)과
> 분할(split) 열이 추가되어 19개 열이 기록된다.**

(뒤 문장은 같은 문단 끝, "2021-01-03 02:00부터 2025-12-31 00:00까지의 관측을
포함한다." 다음에 붙인다.)

## 5. 수식 번호 부여

**대상:** 독립된 줄에 있는 수식 **12개**. 표 3-8 안의 지표 정의(6개)와 문장 안에
끼워 쓴 수식(3.6.5의 √8,760 등)은 **번호를 붙이지 않는다.**

**형식:** 수식 오른쪽 끝에 장-순번 `(3-1)`. Word에서는 수식 이미지 뒤에 오른쪽 정렬
탭을 두고 번호를 넣는다. 열두 개 모두 같은 방식으로.

| 번호 | 위치 | 수식 바로 앞 문장 (Ctrl+F용) |
|---|---|---|
| (3-1) | 3.1.4 | "자산 i, 변수 f, 시점 t에 대해" |
| (3-2) | 3.2.1 | "…관측 st로 주어지며, 다음 3차원 텐서다." |
| (3-3) | 3.2.1 | "…softmax 변환을 거쳐 목표 비중 … 정규화된다." |
| (3-4) | 3.2.1 | "두 비중의 관계는 다음과 같다." |
| (3-5) | 3.2.1 | "…포트폴리오 가치의 로그 변화량으로 정의한다." |
| (3-6) | 3.2.2 | "…실제로 발생한 거래량을 의미하며, 다음과 같이 정의한다." |
| (3-7) | 3.2.2 | "…평가용 단순수익률은 Rt로 표기한다." |
| (3-8) | 3.6.2 | "매 재표집에서 다음 통계량을 계산한다." |
| (3-9) | 3.6.4 | "시드 s에서 두 정책망의 Sharpe 차이" |
| (3-10) | 3.6.4 | "…n = 5개 시드에 대한 대응표본 t 신뢰구간" |
| (3-11) | 3.6.5 | "…목표 비중 벡터의 L₁ 변화량" |
| — | 4.5.1 | "인접 시점 목표 비중의 9개 성분 절대차의 합" — **아래 참고** |

**4.5.1은 번호를 붙이지 말고 수식을 참조로 바꾼다.** 3.6.5의 (3-11)과 같은 식을 다시
쓴 것이라, 결과 장에서 정의를 반복할 필요가 없다.

> 정책이 매 시점 지시하는 비중이 얼마나 변하는지를 측정했다. 인접 시점 목표 비중의
> 9개 성분 절대차의 합 [수식 이미지] 의 평균값은 다음과 같다.
> →
> 정책이 매 시점 지시하는 비중이 얼마나 변하는지를 측정했다. 3.6.5절에서 정의한
> 목표 비중의 시점 간 L₁ 변화량 Δₜ(식 3-11)의 평균값은 다음과 같다.

**본문의 "위 식" 표현을 번호로 바꾼다.**
- 3.2.2 "**위 식의** 적용에 관하여 다음 세 가지를 밝혀 둔다." → "**식 (3-7)의** 적용에
  관하여…"
- 같은 문단 바로 아래 "첫째, **이 식은** 거래비용이 기간 초에 발생하여…" → "첫째,
  **식 (3-7)은** 거래비용이…"
- 5차 기준으로 "위 식/이 식"은 이 두 곳뿐이다(확인 완료)
