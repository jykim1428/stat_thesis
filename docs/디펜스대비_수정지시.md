# 수정 1. 5.2에 연구질문 3의 답 추가 — **은아**

**우선순위: 최상** · 위치: 5.2절, **5.2.3 바로 앞에 새 소절로 삽입**

## 문제

1.2절에서 연구질문 3개를 제시하는데, 5.2가 **두 개만 명시적으로 답한다.**

| 절 | 서술 | 상태 |
|---|---|---|
| 5.2.1 | "연구질문 1에 대해서는, PPO가 전통 전략을 능가했다는 증거를 얻지 못했다…" | ✅ |
| 5.2.2 | "연구질문 2에 대해서는, 본 연구의 설계로 구조의 효과를 분리할 수 없다…" | ✅ |
| — | **연구질문 3에 대한 답이 없음** | ❌ |
| 5.2.3 | "정적 배분으로 수렴한 원인은 특정할 수 없다…" | 원인 분석이지 RQ3의 답이 아님 |

원고 전체에서 "연구질문 3에 대해서는"이 **0건**이다. 심사에서 "세 질문 중
하나는 답을 안 했다"는 지적이 나오면 반박할 문장이 없다.

## 작업

**5.2.3을 5.2.4로 밀고**, 그 자리에 다음 소절을 새로 넣는다.

```
5.2.3 국면에 따른 성과와 배분 변화
```

내용은 **이미 원고에 있는 사실만 조합**해서 쓴다. 새로 분석하지 않는다.

- 성과: 상승 국면 Sharpe 2.203 / 2.206, 조정 국면 -0.194 / -0.222.
  국면 간 차이(약 2.4)가 정책망 간 차이(0.003~0.028)보다 두 자릿수 이상
  크다 (4.2절, 4.6절)
- 배분 변화: 시점 간 목표 비중 변화량이 10⁻⁸ 수준이고(4.5.1절, 표 4-7),
  드로다운 구간과 평시의 현금 비중 차이가 10⁻⁹ 미만이다(4.5.4절, 표 4-10).
  즉 **국면이 바뀌어도 배분은 바뀌지 않았다**
- 따라서 답: 성과는 국면에 강하게 의존했으나, 그 의존은 **정책이 국면에
  대응한 결과가 아니라 고정된 배분이 시장을 그대로 받은 결과**다
- 한계 한 문장: 국면 경계가 사후 지정이므로(3.5.3절) 이는 사후 분류된
  구간에서의 관찰이며, 실시간 국면 식별 운용의 성능이 아니다

**분량: 한 단락(4~6문장) + 필요시 한계 한 문장.** 길게 쓰지 않는다.

## 주의

- "일반화되었다 / 일반화되지 않았다"로 단정하지 말 것. RQ3 문구가
  "성과와 투자 비중 변화는 **어떻게 나타나는가**"로 완화되어 있으므로,
  답도 서술형으로 맞춘다
- 5.2.3 → 5.2.4 번호 변경에 따라 **"5.2.3절" 참조 4곳을 전부 5.2.4절로
  수정한다.** 확인 결과 4곳 모두 "정적 배분의 원인"을 가리키고 있어
  일괄 수정이 맞다. 위치는 다음과 같다.

  | 위치 | 문맥 |
  |---|---|
  | 3.2.2 (거래비용 처리) | "이 처리 방식이 학습된 정책에 미치는 영향은 5.2.3절과 5.4절에서 논의한다" |
  | 3.2.1 (보상 정의) | "이 설계가 학습된 정책의 행동에 미친 영향은 5.2.3절에서 논의한다" |
  | 5.4.1 (원인 식별의 한계) | "네 가지가 모두 가능하며(5.2.3절)" |
  | 5.5.1 (정적 배분의 원인 규명) | "5.2.3절의 네 가설을 구별하려면" |

  새로 쓰는 5.2.3(RQ3 답)을 가리키는 참조는 **만들지 않아도 된다**

# 수정 2. 5.4.2에 자산 선정 편향 추가 — **은아**

**우선순위: 높음** · 위치: 5.4.2 평가 범위의 한계, **마지막 항목으로 추가**

## 문제

3.1.1절에 자산 선정 기준이 이렇게 적혀 있다.

> "자산은 시가총액 상위 종목 중 **전 기간 데이터 가용성**을 기준으로
> 선정하였다"

2021~2025년 **내내 살아남은** 8종만 골랐다는 뜻이다. 같은 기간
상장폐지되거나 가치가 붕괴한 자산은 표본에서 빠졌다(생존 편향,
survivorship bias). **이 한계가 5장에 없다.**

5.4.2는 현재 네 항목(OOS 국면 2개 / Fold 2 validation 부재 / 정책망 2종 /
벤치마크 4종)만 다루고, 5.5의 "자산 범위 확대"는 후속 과제일 뿐 편향으로
서술하지 않는다.

## 작업

5.4.2의 기존 항목들과 같은 형식으로 한 항목 추가.

- 제목 문장: 자산 선정에 생존 편향이 있다 (앞 항목들처럼 평서문으로 시작)
- 내용: 8종은 전 기간 데이터 가용성을 기준으로 선정되었으므로(3.1.1절),
  해당 기간에 상장폐지·가치 붕괴한 자산이 표본에서 제외되었다
- **편향의 방향을 함께 적는다**: 생존한 자산만 포함하면 벤치마크(특히
  Equal-Weight)와 PPO 양쪽의 성과가 모두 위로 치우친다. 다만 본 연구의
  결론은 "PPO가 벤치마크 대비 우위를 보이지 못했다"이므로, 이 편향이
  결론을 만들어낸 요인으로 보기는 어렵다

**분량: 3~4문장.**

## 주의

마지막 "편향 방향" 서술은 3.2.2절이 진입비용 면제를 다룰 때 쓴 논법과
같다. 그 문단을 참고해 톤을 맞출 것. **편향을 축소하거나 변명하는 투로
쓰지 말고, 방향을 밝히는 데서 멈춘다.**

# 수정 3. 3.2.2 거래비용 처리 서술 보강 — **유지**

**우선순위: 높음** · 위치: 3.2.2절 첫 문단 (현재 "본 연구에서 거래비용은
학습과 평가 단계에서 서로 다르게 처리된다"로 시작하는 문단)

## 문제

심사에서 가장 강하게 들어올 지점이다. 현재 서술:

> "PPO 학습 과정에서는 환경의 거래비용률이 **설정되지 않아(기본값 0)**
> 거래비용이 보상에 반영되지 않는다"
> "즉 거래비용을 보상에 내재화하는 방식이 아니라, 최종 성과 평가 단계에서
> **사후적으로 반영하는 방식이다**"

문장이 중립적이어서 **의도된 설계처럼 읽힌다.** 심사위원은 "비용 0으로
학습한 정책을 비용 0.1%로 채점했으면 목적함수가 틀린 것이고, PPO가 못
이긴 건 알고리즘 탓이 아니라 설계 탓"이라고 공격한다. 이때 "사후적으로
반영하는 방식"이라는 표현은 변명으로 들린다.

## 작업

문단을 **"선택이 아니라 제약이었음"이 드러나게** 고친다. 셋 다 반영.

1. **학습·평가 목적함수가 불일치한다는 점을 명시적으로 쓴다.**
   현재는 "서로 다르게 처리된다"로 완화돼 있다. "학습이 최적화한 목적과
   평가가 채점한 기준이 일치하지 않는다"는 문장을 넣는다
2. **결론의 적용 범위를 이 문단에서 한정한다.**
   "따라서 본 연구의 결과는 거래비용을 보상에 내재화하지 않은 설정에서의
   PPO 성과로 한정해 해석해야 한다" 수준의 문장
3. **5.4로 연결.** 이 처리가 한계임을 5.4절에서 다룬다고 명시
   (현재는 5.2.3·5.4를 가리키고 있으나, 한계라는 성격이 드러나지 않음)

**값·설정은 바꾸지 않는다.** cost_rate 0.001, 기본값 0이라는 사실 자체는
그대로 두고 **서술 톤만** 조정한다.

## 주의

- "버그였다 / 실수였다" 식의 고백조로 쓰지 말 것 (용어사전 §10 금지).
  **"이 설정은 ~하지 않았다"는 사실 서술 + 결론 범위 한정**의 형태로 쓴다
- 5.2.3 ②(보상 설계)와 5.4.3(거래 환경 단순화)에 이미 관련 서술이 있다.
  **중복 서술을 늘리지 말고**, 3.2.2에서는 범위 한정만 하고 상세 논의는
  5장을 가리킬 것
