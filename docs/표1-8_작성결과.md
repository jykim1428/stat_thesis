## A-3. 용어사전 핵심 규칙 정리 (정독 후 추출)

**1. 논문 전체 통일 용어** — PPO(첫 등장 시 Proximal Policy Optimization(PPO)), 국면(영문 병기 시 regime; "레짐·시장상태" 금지), 표본외(out-of-sample, OOS), 시드(seed), 비중(weights)/목표 비중(target_weights)("가중치·웨이트" 금지), 순수익률(net)/총수익률(gross) 반드시 구분, 평가 체계 명칭은 "국면 보존 확장 윈도우 2-fold 전진 평가"(**"교차검증" 금지**).

**2. 정책망·전략 공식 표기** — **MLP**, **Transformer**(mlp, 트랜스포머, MLP망 금지). 벤치마크: **Buy & Hold BTC**, **Equal-Weight**, **Minimum-Variance**(코드명 markowitz → 논문에서 Markowitz 금지), **Risk Parity**. 확정 후보: MLP candidate03(learning_rate 1e-3), Transformer candidate04(n_layers 1).

**3. 국면·Fold 표기** — 개별 국면은 "한글명 + 코드명 병기"(예: 상승 국면(bull_2024)); bull_2024=상승(Fold 1 OOS), choppy_2025=**조정**(Fold 2 OOS; "횡보" 금지, 횡보는 side_2023), side_2023=횡보(검증). Fold는 **Fold 1 / Fold 2**(fold1, 폴드1 금지). choppy_2025의 실제 종료일은 2025-12-31. OOS 스텝 수: Fold 1 10,656 / Fold 2 8,713.

**4. 지표명·약어** — Sharpe, Sortino, Calmar, MDD(음수 표기), 변동성(Volatility; 연율화 표준편차), CAGR, 평균 turnover(Average Turnover), 누적 거래비용률(Total Transaction Cost; 화폐 금액 아님). 연율화 상수 8,760, 무위험수익률 0, 계산은 `evaluate.py`·empyrical-reloaded 0.5.12.

**5. 자산 인덱스 순서** — 0=CASH, 1~8 = **ADA, AVAX, BNB, BTC, DOGE, ETH, SOL, XRP**(알파벳순, 시가총액순 아님). 본문은 티커만(BTC), 표·코드 참조 시에만 BTCUSDT. *(표 1~8에는 자산별 비중이 없어 직접 적용 대상은 없음)*

**6. 숫자·자릿수** — Sharpe/Sortino/Calmar/표준편차/p-value/신뢰구간 소수점 3자리, MDD/변동성/CAGR 소수점 1자리 %, 평균 turnover 소수점 4자리 %, 신뢰구간은 대괄호 `[-0.031, +0.037]`.

**7. 단위·기호** — 퍼센트는 % 표기, 표준편차는 ±, 신뢰구간 양수에 + 부호, turnover 식은 Σ|target_weights_t − weights_(t−1)|/2(금지 정의: Σ|weights_t − weights_(t−1)|/2), 순수익률 = gross − turnover × cost_rate, 거래비용률 편도 0.1%.

**8. 금지 표현 → 대체 표현**

| 금지 | 대체 |
|---|---|
| "통계적으로 동등/동일하다" | "차이가 0과 다르다는 통계적 증거를 얻지 못했다" |
| "PPO가 이겼다/졌다" | 수치·검정 결과 중심 서술 |
| "사전 정의된 선택 기준" | "validation 결과 검토 후 확정하고 OOS 확인 전 동결한 기준" |
| "사전 계획된 5-seed" | "post-hoc robustness extension" |
| gross·net 혼용, weights·target_weights 혼용 | 본문 표는 전부 net, 두 용어 구분 |
| 국면을 "교차검증 fold"로 서술 | 2-fold 전진 평가 |
| choppy_2025를 "횡보"로 표기 | 조정(국면) |
| 버그 수정 이력 고백조, "독립 검토" | "AI 보조 코드 검토 및 재실행 검증" |
| 숫자 재계산·스크립트 재실행 | 전사만 |

**9. 표 제목·캡션·각주 규칙** — 모든 성과표에 "거래비용 0.1% 차감 후(net) 기준" 명시; 5-seed 결과에는 시드 확장 각주(post-hoc, 3-seed 원본 보존)가 필수(§5.2); Sharpe>0·CAGR<0 현상 설명 각주(§4); 통계표에는 방법(stationary block bootstrap, 블록 24, 2,000회, 95%), 보정(Holm-Bonferroni, 비교 수 16), 결론 한정(두 OOS 국면에 한정) 명시; quantstats는 근거로 사용 금지.
