## 3. 강화학습 환경

### 3.1 상태 (State)

- **관측 shape: `(3, 8, 50)`** = (가격 피처 3개, 자산 8종, lookback 50시간)
- **lookback 기호: `TIME_WINDOW = 50`** (50시간)
- 본문 표기: "관측은 (피처 × 자산 × 시간) = (3, 8, 50) 텐서"

### 3.2 행동 (Action)

- **action shape: `(9,)`** = 자산 8 + 현금 1
- **action space: `Box(low=-10.0, high=10.0, shape=(9,))`**
  - ⚠️ `[0,1]`이 아님. softmax 정규화 전 raw action이라 범위 제약을 풀어둔 것
- **목표 비중(target_weights):** raw action을 **softmax 정규화**한 값.
  가격 변동이 반영되기 **전**의 리밸런싱 목표
- **사후 비중(weights):** 가격 변동이 반영된 **기말(end-of-period)** 실제 비중

> 🚩 `weights`와 `target_weights`를 절대 혼용하지 말 것.
> turnover 계산과 4.5 행동 진단이 전부 이 구분에 의존한다.

### 3.3 보상 (Reward)

- **보상 = 로그 수익률**: `reward_t = log(V_t / V_{t-1})`
  - `V_t` = t 시점 기말 포트폴리오 가치
- **reward_scaling = 1** (스케일링 없음)
- 본문 표기: "보상은 스텝별 포트폴리오 가치의 로그 변화량으로 정의한다"

### 3.4 거래비용 및 turnover

- **거래비용률 `cost_rate = 0.001` (편도 0.1%)**
- **turnover 정의 (반드시 이 식):**

  ```
  turnover_t = Σ | target_weights_t − weights_{t−1} | / 2
  ```

  - t 시점 **목표 비중**과, 직전 스텝 종료 후의 **실제 비중**의 차이
  - t=0은 초기 진입이므로 turnover = 0
- **금지된 정의:** `Σ|weights_t − weights_{t−1}|/2`
  - 가격 변동으로 인한 비중 변화까지 거래량으로 오계상 → **약 1.2~1.45배 과대계상**
  - 본문에는 "왜 이 정의를 쓰는지"를 서술하되, "초기에 잘못 짰다가 고쳤다"는
    식으로 쓰지 말 것 (§7 참고)
- **순수익률:** `net_return_t = gross_return_t − turnover_t × cost_rate`

## 4. 성과 평가 지표

- **계산 모듈:** `src/cryptoagent/envs/evaluate.py` — **모든 모델·벤치마크가
  동일 함수로 평가됨** (이 원칙을 3.6에 명시)
- **라이브러리:** `empyrical-reloaded` 0.5.12
- **연율화 상수: `periods_per_year = 8760` (= 24 × 365)**
  - ⚠️ 1시간봉이므로 252(일봉)나 365가 아니다
  - quantstats HTML 리포트는 일봉 기본값을 써서 Sharpe가 틀리게 나온 적이
    있음 → **quantstats 리포트는 참고용(non-canonical)**, 본문 수치 근거 아님
- **무위험 수익률: `risk_free = 0`**

| 지표 | 표기 | 정의 |
|---|---|---|
| Sharpe ratio | Sharpe | 연율화 초과수익 / 연율화 변동성 (net 기준) |
| Sortino ratio | Sortino | 하방 변동성 기준 |
| Calmar ratio | Calmar | 연율화 수익률 / MDD |
| Maximum Drawdown | MDD | 최대 낙폭 (음수 표기) |
| Volatility | 변동성 | 연율화 표준편차 |
| CAGR | CAGR | 연평균 복리 수익률 |
| Average Turnover | 평균 turnover | 스텝별 turnover의 산술평균 |
| Total Transaction Cost | 총 거래비용 | turnover × cost_rate 누적합 |

> ⚠️ **모든 지표는 순수익률(net) 기준으로 보고한다.** gross 값은
> `benchmarks_summary.csv`에 함께 있지만 본문 표에는 net만 쓴다.
> 표 제목이나 각주에 "거래비용 0.1% 차감 후" 를 반드시 명시할 것.

> ⚠️ **Sharpe > 0 인데 CAGR < 0 인 경우가 있다** (조정 국면의 Buy&Hold BTC:
> Sharpe 0.066, CAGR -6.7%). Sharpe는 산술평균, CAGR은 기하평균(복리) 기반이라
> 생기는 차이다. "Sharpe가 양수니 수익이 났다"고 쓰면 틀린 문장이 된다.

## 5. Walk-Forward 설계

- **정식 명칭: regime-preserving expanding-window 2-fold forward evaluation**
  - 한글: **국면 보존 확장 윈도우 2-fold 전진 평가**
  - ⚠️ 일반적인 k-fold cross-validation이 **아니다**. "교차검증"이라고 쓰지 말 것
- **워밍업:** 각 평가 구간 시작 직전 **50시간**을 관측 구성에만 사용.
  거래·보상·성과 기록은 OOS 시작 시점부터

| | Fold 1 | Fold 2 |
|---|---|---|
| 하이퍼파라미터 선택 | train: bull_2021+bear_2022<br>val: side_2023 | Fold 1 확정 설정 그대로 사용 |

### 5.1 확정 후보 (locked candidates)

| 정책망 | 후보 ID | 하이퍼파라미터 | validation Sharpe (3-seed) |

## 6. 통계적 유의성 검정

- **방법: stationary block bootstrap** (`arch.bootstrap.StationaryBootstrap`)
- **블록 크기: 주 분석 24시간, 민감도 확인 168시간**
- **복원 추출 횟수: 2,000회**
- **신뢰수준: 95%**
- **통계량:** 매 리샘플에서
  `mean_seed[ Sharpe(PPO_seed) − Sharpe(benchmark) ]`
- **풀링 방식:** PPO 5-seed + 벤치마크 1개 = **6개 시계열을 동일한 블록
  인덱스로 공동 리샘플**(jointly resampled). 시계열별로 따로 뽑지 않음
- **다중비교 보정: Holm-Bonferroni, 비교 수 16**
  (정책 2 × 벤치마크 4 × fold 2)
- **결과: 16개 비교 전부 보정 후 비유의. 최소 p = 0.118**
  (Transformer vs Minimum-Variance, 조정 국면)

> 🚩 **가장 중요한 금지 사항**
> "PPO와 벤치마크가 통계적으로 **동등하다**" → **틀린 문장. 절대 금지.**
> 올바른 표현: "PPO와 벤치마크 간 Sharpe 차이가 **0과 다르다는 통계적 증거를
> 얻지 못했다**"
> 이유: 비유의는 동등성의 증거가 아니다. 동등성 주장에는 사전에 정의된 실질적
> 동등성 범위에 대한 equivalence test가 필요하며, 본 연구는 수행하지 않았다.

> 가장 잘 방어했다고 서술하는 것이 정확하다.

- **목표 비중의 스텝 간 평균 변화량 (diagnostics.json 실측값):**

  해당"** → 사실상 불변
  - ⚠️ `results_section_draft.md`에 "3×10⁻⁹~1×10⁻⁸"로 느슨하게 적혀 있으나,
    실측값은 위 표와 같다. **본문에는 위 표의 값을 쓸 것**

- **PPO 순수익률과 Equal-Weight 순수익률의 상관계수 (실측값):**
  MLP 0.9994(상승)/0.9995(조정), Transformer 0.9991(상승)/0.9997(조정)
  → 본문 서술: **"0.999 이상"**
- **드로다운 구간 vs 평시 목표 현금 비중:** 네 조합 모두 **소수점 6자리까지 동일**
  (예: MLP 조정 국면 0.110257 / 0.110257) → 방어적 현금 이동을 학습하지 못함
- **시드 간 시간평균 목표 비중 차이:** 자산별 표준편차 약 1~3%p,
  최대 범위 약 8%p (현금 비중 약 8.5% ~ 14.2%)
  - ⚠️ **출처 주의**: `diagnostics.json`에는 **5-seed 평균만** 저장되어 있고
    시드별 값은 보존되지 않는다. 위 수치는 `results_section_draft.md`에
    기록된 값으로, frozen 산출물만으로는 재확인할 수 없다.
    (참고: 5-seed 평균 현금 비중은 MLP 10.39%/11.03%,
    Transformer 11.42%/11.81%로 위 범위와 정합적이다)
  - **본문에 이 수치를 쓰기 전 준영에게 확인할 것.** 필요하면
    `{policy}_target_allocation_seed_range.png` 그림으로 대체 서술 가능
- ⚠️ "모든 시드가 동일한 배분을 학습했다"가 **아니다**. 각 시드는 서로 다른
  **정적(static) 포트폴리오**를 학습했고, 그 배분이 시드 내부에서 시간에
  따라 변하지 않은 것이다
